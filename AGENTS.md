# Project guidance

- Before changing the visual design, read [Design.md](Design.md) and use its color, typography, spacing, component, and responsive guidance.
- Keep the music room's existing playback, playlist, and search behavior working while applying the design reference.
- `SpotifyMixUI` and `SpotifyMixUITitle` are not bundled with this project; use the system font fallbacks in the design document unless licensed fonts become available.
