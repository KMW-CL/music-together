# music together

시각 디자인의 기준은 [Design.md](Design.md)입니다. 디자인을 수정할 때 먼저 이 문서를 확인하세요.

YouTube 검색이나 링크로 친구들과 같은 시점에 음악을 듣는 작은 웹 앱입니다. 기본적으로 방에 들어온 사람은 누구나 공유 재생목록에 곡을 추가하고 순서를 바꾸거나 삭제할 수 있습니다. 방장은 상단의 권한 버튼으로 재생목록 관리를 방장에게만 제한할 수 있습니다. 현재 곡, 재생 위치, 재생과 일시정지도 방 전체에 공유됩니다.

## 실행

Node.js 20 이상에서 다음 명령을 실행하세요. 별도 패키지 설치는 필요하지 않습니다.

```bash
npm start
```

브라우저에서 `http://localhost:3000`을 열 수 있습니다. `PORT` 환경 변수로 포트를 바꿀 수 있습니다.

```bash
npm test
```

## 다른 기기에서 접속하기

이 앱은 하나의 서버가 방과 재생 상태를 공유하고, 음악은 각 참가자의 브라우저에서 YouTube로 재생합니다. `localhost`는 접속한 기기 자신을 뜻하므로 다른 사람에게 `localhost` 주소를 보내면 접속할 수 없습니다.

- **같은 사내망·와이파이:** 서버 화면의 `같은 네트워크에서 접속` 주소 중 실제 이더넷 또는 와이파이 주소를 사용합니다(예: `http://192.168.0.10:3000`). 방장도 이 주소로 접속해 방을 만든 뒤 **초대 링크 복사**로 링크를 공유해야 합니다. 가상 네트워크 어댑터 주소는 제외하세요. 다른 기기에서 페이지가 열리지 않으면 서버 컴퓨터의 방화벽과 사내망의 기기 간 접속 정책을 확인해야 합니다.
- **다른 네트워크·인터넷:** 외부에서 접근 가능한 서버에 앱을 두고 HTTPS 도메인으로 접속합니다(예: `https://music.example.com`). 방장과 참가자 모두 같은 도메인을 사용해야 초대 링크가 올바르게 만들어지고 최근 접속한 방 목록도 같은 주소에 저장됩니다. 회사 컴퓨터를 외부에 직접 공개하기 전에는 회사의 네트워크 담당자와 접속 방식 및 접근 제한을 확인하세요.

서버가 꺼지면 방에 접속할 수 없습니다. 방과 재생목록은 서버의 `data/rooms.json`에 저장되므로, 서버를 옮길 때 기존 방을 유지하려면 이 파일도 안전하게 옮기고 저장 공간이 재시작 후에도 유지되도록 해야 합니다. 이 파일과 YouTube API 키는 GitHub 저장소에 포함되지 않습니다.

## YouTube 사전 검사 설정

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들거나 선택합니다.
2. **API 및 서비스 → 라이브러리**에서 **YouTube Data API v3**를 사용 설정합니다.
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**를 선택합니다. 키의 **API 제한**은 **YouTube Data API v3**로 설정합니다. 서버의 공인 IP가 고정되어 있다면 애플리케이션 제한도 IP 주소로 설정할 수 있습니다.
4. 이 프로젝트의 `data/youtube-api-key.txt` 파일을 만들고 발급받은 키만 한 줄로 넣습니다. 이 파일은 Git에서 제외되며 브라우저로 전송되지 않습니다. 대신 서버를 시작하기 전에 `YOUTUBE_API_KEY` 환경 변수를 설정해도 됩니다.
5. 음악방 페이지를 새로고침해 **사전 검사 켜짐** 표시를 확인합니다. 로컬 키 파일은 서버를 다시 시작하지 않아도 다음 요청부터 적용됩니다. 환경 변수는 서버를 다시 시작해야 적용됩니다.

곡 추가 버튼을 누르면 브라우저가 작은 YouTube 삽입 플레이어를 먼저 열어 재생 차단 오류를 확인합니다. 오류가 나거나 확인 시간이 초과되면 재생목록에 넣지 않습니다. 키가 설정되어 있으면 그다음 서버에서 공개 여부, 삽입 허용 여부, 연령 제한도 검사합니다. 키가 없어도 브라우저의 삽입 플레이어 검사는 동작합니다. YouTube가 실제 재생을 시작할 때에만 제한을 알리는 영상도 있어 사전 검사가 모든 재생 실패를 보장해서 잡지는 못합니다. 재생 중 오류가 나면 자동 건너뛰기도 계속 동작합니다.

곡 추가 영역의 **유튜브에서 검색하기** 버튼을 누르면 검색 팝업이 열립니다. 팝업에서 곡이나 아티스트를 검색하고 재생목록에 추가할 수 있으며, 닫기 버튼이나 Esc 키로 닫을 수 있습니다. 링크 입력은 곡 추가 영역에서 바로 사용할 수 있습니다. 검색은 같은 API 키를 사용하며 방에 들어온 누구나 실행할 수 있습니다. 음악 카테고리의 후보를 25개씩 받아 공식 MV와 아티스트 채널의 곡을 우선 표시합니다. 검색 결과는 스크롤 없이 카드형 페이지로 표시합니다. 넓은 화면에는 4개, 좁거나 낮은 화면에는 2개 또는 1개씩 표시하며 **다음**·**이전** 버튼이나 좌우 방향키로 넘길 수 있습니다. 받아온 결과를 모두 보면 **다음**에서 YouTube의 다음 검색 결과를 불러옵니다. 분류나 영상 제목이 부정확하면 원치 않는 결과가 섞이거나 곡이 빠질 수 있으므로, 검색에서 찾지 못한 곡은 링크로 추가할 수 있습니다. 결과에서 **추가**를 누르면 링크 입력과 동일한 재생 검사를 거칩니다. 같은 검색어와 페이지의 결과는 서버가 30분 동안 재사용합니다. [YouTube 공식 할당량 문서](https://developers.google.com/youtube/data/determine_quota_cost)에 따르면 기본 검색 한도는 하루 100회입니다. 한도에 도달하면 링크 입력은 계속 사용할 수 있습니다.

검색 결과 썸네일에는 영상 길이가 표시됩니다. 검색 페이지마다 YouTube 영상 상세 정보를 한 번 더 조회하며, 길이 정보를 받지 못한 영상은 `--:--`로 표시합니다. 길이 조회 요청 자체가 실패하면 검색 창에 안내를 표시하며, 같은 검색어로 다시 검색할 때 캐시된 검색 결과의 길이를 재조회합니다.

## 현재 범위

- 방을 만들거나 초대 링크로 접속하면 홈의 **최근 접속한 방**에 기록됩니다. 같은 브라우저와 접속 주소에서 최대 8개까지 보이며, 브라우저나 컴퓨터를 다시 켠 뒤에도 목록에서 재입장할 수 있습니다. `×`는 방문 기록만 지우고 방 자체는 삭제하지 않습니다. 방문 기록은 브라우저 저장소에, 방과 재생목록은 서버의 `data/rooms.json`에 각각 저장됩니다.
- 새 방을 만든 브라우저가 방장입니다. 방장 권한은 그 브라우저에 저장되며 초대 링크에는 포함되지 않습니다. 기존에 만들어진 방에는 방장 정보가 없어, 상단의 **방장 등록** 버튼을 먼저 누른 사람이 방장이 됩니다.
- 기본값에서는 모두가 곡을 추가·선택·이동·삭제하고 반복·랜덤 설정을 바꿀 수 있습니다. 방장이 상단 버튼을 눌러 **방장만 목록 조작**으로 바꾸면 다른 참가자의 목록 조작은 화면과 서버에서 차단됩니다. 재생·일시정지·위치 이동·다음 곡은 계속 함께 조작할 수 있습니다.
- 재생, 일시정지, 위치 이동은 영상 아래의 공용 버튼과 진행 막대로 조작합니다. 각 브라우저는 방의 재생 상태를 따라가며, 자동재생이 막힌 기기에서는 **함께 듣기 시작**을 눌러야 합니다.
- **내 볼륨**은 각 브라우저에서만 적용됩니다. 스피커 버튼을 누르면 음소거되고 다시 누르면 직전 볼륨으로 돌아옵니다. 슬라이더를 0%로 옮겨도 스피커 버튼으로 직전 볼륨을 복원할 수 있습니다. 설정값은 해당 브라우저에 저장되어 새 곡이나 새로고침 후에도 유지됩니다. 다른 사람의 볼륨과 방의 재생 상태에는 영향을 주지 않습니다.
- **영상 작게 보기**는 현재 브라우저의 YouTube 플레이어를 220×220으로 줄입니다. 선택은 이 브라우저에 저장되고, 다른 사람의 화면이나 방의 재생 상태에는 영향을 주지 않습니다. YouTube 삽입 플레이어 정책상 재생 중 영상을 완전히 가리거나 오디오만 따로 재생하지 않습니다.
- 검색 결과 또는 링크로 곡을 추가하면 재생목록 끝에 쌓입니다. 첫 곡은 바로 준비됩니다. 누구나 목록에서 곡을 선택해 재생하거나 삭제할 수 있습니다. 각 곡의 왼쪽 손잡이를 끌어 순서를 바꿀 수 있고, 키보드에서는 손잡이를 선택한 뒤 방향키 또는 Home/End 키로 옮길 수 있습니다.
- 재생목록의 **반복 재생**, **한 곡 반복**, **랜덤 재생** 글씨 버튼은 방 전체에 공유됩니다. 반복 재생은 기본으로 켜져 있어 마지막 곡 다음에 첫 곡으로 돌아갑니다. 한 곡 반복을 켜면 현재 곡이 끝날 때 같은 곡을 다시 시작하며, 다음 곡 버튼을 누르면 다음 곡으로 이동합니다. 두 반복 버튼은 서로 전환되고 둘 다 끄면 마지막 곡에서 재생이 멈춥니다. 랜덤 재생은 남은 곡을 중복 없이 섞어 재생하며 반복 재생과 함께 사용할 수 있습니다. 한 곡 반복과 랜덤 재생은 서로 전환됩니다. 목록에 중복 항목을 만들지 않습니다.
- 방과 재생목록은 로컬 `data/rooms.json`에 저장됩니다. 서버를 다시 켜면 재생은 일시정지된 상태로 복원됩니다. 이전 버전의 현재 곡, 다음 곡, 지난 곡도 하나의 재생목록으로 옮겨집니다.
- 곡 이름을 직접 입력하지 않으면 재생 시 YouTube 플레이어에서 확인한 제목으로 바뀝니다. 아직 재생하지 않은 곡은 영상 ID로 표시될 수 있습니다.
- 브라우저의 자동재생 정책 때문에 참가자는 재생 시작 버튼을 한 번 눌러야 할 수 있습니다.
- 일부 유튜브 영상은 외부 사이트 재생이 제한됩니다. 플레이어에서 삭제·비공개(100) 또는 삽입 금지(101, 150) 오류가 나면 다음 곡이 있을 때 자동으로 건너뜁니다. 다음 곡이 없거나 브라우저 환경 오류가 나면 오류 안내를 보여줍니다. 제한된 영상을 이 앱에서 강제로 재생할 수는 없습니다.
